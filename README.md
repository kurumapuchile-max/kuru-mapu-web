# Kuru Mapu — Sitio Web

## Instrucciones para agregar el logo

1. Copiar el archivo del logo como `logo.png` en esta misma carpeta
2. El sitio lo cargará automáticamente en el nav y el footer

## Deploy en Railway

1. Crear carpeta `kuru_mapu_web` en GitHub
2. Subir `index.html` y `logo.png`
3. En Railway: New Project → GitHub repo → Deploy
4. Railway sirve archivos estáticos automáticamente

## Deploy en Vercel (alternativa, más simple)

1. Ir a vercel.com
2. Import Git Repository
3. Seleccionar el repo
4. Deploy — listo en 30 segundos
